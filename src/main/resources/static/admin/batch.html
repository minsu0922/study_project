배치는 GitHub Actions에서 돕니다 — 이 화면에서 켜거나 즉시 실행할 수 없습니다.
켜고 끄기: application.yml의 batch-enabled를 고쳐 커밋합니다.
한 번 돌리기: 저장소의 Actions → llm-daily → Run workflow. 주제 범위 목록의 복사 버튼이 거기 넣을 값을 만들어 줍니다.
지나간 날짜를 손으로 채울 때는 --suffix를 붙입니다 — 안 붙이면 그날 예약 실행이 죽습니다.

문서는 문제와 규칙이 다릅니다. --suffix가 안 먹습니다 — 근거 문서를 가리키는 유일한 통로가 --document-date, 즉 날짜라서 접미사가 붙으면 아무도 못 부르는 파일이 됩니다(문서는 날짜로, 문제는 이름으로 부릅니다).
그래서 같은 날짜에 문서를 두 편 만들 수 없습니다. 이미 있으면 조용히 건너뜁니다 (요금은 안 나갑니다). 한 편 더 뽑아 보려면 date를 문서일이 아닌 날짜로 주세요 — 그날 예약 실행은 문제 파일을 쓰므로 경로가 달라 안 부딪힙니다.
